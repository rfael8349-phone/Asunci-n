# Ruinas 16-Bit 3D v2 — Esqueletos y Zombis Rabiosos

Acción 3D pixelada estilo 16-bit con oleadas de esqueletos, zombis rabiosos y jefes periódicos.

## Controles
- **Moverse:** `WASD` o `Flechas` (en móvil: joystick izquierdo).
- **Tajo rápido:** Clic / toque rápido en pantalla, `J` / `F` o botón `TAJO`.
- **Golpe fuerte (mayor alcance y daño, usa estamina):** `K` o botón `GOLPE FUERTE`.
- **Esquive con invulnerabilidad breve (usa estamina):** `Shift` o botón `ESQUIVE`.
- **Saltar:** `Espacio` o botón `SALTO`.
- **Reiniciar al caer:** `R` o tocar la pantalla.
